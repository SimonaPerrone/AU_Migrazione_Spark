# MIGRAZIONE_SPARK3_CCE_CALCOLO

## 1. Descrizione Progetto
Job Spark complesso per calcolo CCE (P/PR/PEIN/PREIN) con molti DAO/controller e tracciamento elaborazioni.

Stack attuale: Spark 2.4, Scala 2.11.

## 2. Funzionamento step by step del progetto
1. Parse argomenti e init ambiente.
2. Caricamento tabelle anagrafiche/misure.
3. Esecuzione logiche annullamento + calcolo.
4. Scrittura output e calc track.

## 3. Modifiche da apportare ad ogni singola componente del progetto
- **pom.xml**
  - Upgrade Spark/Scala/plugin test.
- **Codice**
  - Verifica completa SQL Spark 3 (cast/date/null/ANSI).
- **Script deploy**
  - Aggiornare `run_cce.sh` e conf associati.
- **Profili**
  - Validare proprietà `prod/dev/coll`.

## 4. Test da prevedere
- Unit test su controller di calcolo/annullamento.
- Regression test per ogni tipo calcolo (P, PR, PEIN, PREIN).
- Test E2E con KPI business.
- Test incremental vs massivo (calc track).
