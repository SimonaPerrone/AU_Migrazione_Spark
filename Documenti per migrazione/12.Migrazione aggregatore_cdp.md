# MIGRAZIONE_SPARK3_AGGREGATORE_CDP

## 1. Descrizione Progetto
Job Spark per aggregazione consumi CDP con pipeline aggregatori.

Stack attuale: Spark 2.4, Scala 2.11.

## 2. Funzionamento step by step del progetto
1. Init Spark + properties.
2. Lettura dataset CA.
3. Esecuzione aggregatori.
4. Persist/scrittura output.

## 3. Modifiche da apportare ad ogni singola componente del progetto
- **pom.xml**
  - Upgrade Spark/Scala e dipendenze test.
- **Codice**
  - Revisione query SQL/join per semantica Spark 3.
- **Deploy**
  - Aggiornare script in `src/main/resources/deploy`.
- **Logging/config**
  - Validare log4j e proprietà profilo runtime.

## 4. Test da prevedere

- Test integrazione lettura-scrittura Hive.
