# delete-old-partition — Migrazione Spark 2 -> Spark 3

## 1. Descrizione Progetto
- **Tipo:** Scala Spark batch utility.
- **Entry point:** `it.eng.au.deleteOldPartition.Driver`
- **Stack attuale:** Spark `2.4.0.cloudera2`, Scala `2.11.12`, Java 8.
- **Funzione:** eliminazione partizioni vecchie (CCG) da tabelle Hive + cleanup path HDFS.

## 2. Funzionamento step by step
1. `Driver.main` inizializza `Environment` con file properties.
2. Legge lista tabelle (`tables.to.optimize`) e soglia retention.
3. Esegue `SHOW PARTITIONS`, calcola partizioni da rimuovere.
4. Esegue `ALTER TABLE DROP PARTITION` + delete path HDFS.
5. Log finale per ogni tabella/partizione.
