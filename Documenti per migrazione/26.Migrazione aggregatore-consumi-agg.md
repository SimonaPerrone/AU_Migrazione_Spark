# 26.Migrazioneaggregatore-consumi-agg.md

## 1) Descrizione Progetto

### 1.1 Obiettivo e perimetro
`aggregatore-consumi-agg` pubblica consumi gas aggregati per AGG e SBG e genera reportistica SBG.

### 1.2 Stack tecnologico attuale
- Spark `2.4.0.cloudera2`
- Scala `2.11.12`
- Java `8`
- Maven multi-modulo:
  - `aggregatore-common`
  - `aggregatore-agg`
  - `aggregatore-sbg`
  - `query-report-sbg`

### 1.3 Architettura logica
- **Entrypoint AGG:** `aggregatore-agg/.../Driver.scala`
- **Entrypoint SBG:** `aggregatore-sbg/.../Driver.scala`
- **Entrypoint report:** `query-report-sbg/.../Driver.scala`
- I driver leggono `daily_consumption`, `incoerenti`, `esclusi`, applicano sterilizzazione/coefficiente e invocano factory di aggregatori/query.
- **Script deploy:** `run_aggregatore_agg.sh`, `run_aggregatore_sbg.sh`, `run_report_sbg.sh`.

### 1.4 Punti sensibili per Spark 3
- Coerenza versioni parent/moduli.
- Validazione join su dataset di consumo e logica di sterilizzazione.
- Ottimizzazione conf e gestione cache in presenza di più aggregatori/query.

## 2) Funzionamento step by step

1. Avvio modulo AGG/SBG/report tramite script dedicato.
2. Driver inizializza environment e proprietà run.
3. Carica daily consumption + dataset incoerenti/esclusi.
4. Esegue join e trasformazioni valore/sterilizzazione.
5. Applica eventuale `CoefficientController`.
6. Esegue aggregatori/query configurati.
7. Aggiorna metadati tabella info log e termina.
