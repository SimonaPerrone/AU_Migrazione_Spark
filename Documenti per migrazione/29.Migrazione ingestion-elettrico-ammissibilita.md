# 29.Migrazioneingestion-elettrico-ammissibilita.md

## 1) Descrizione Progetto

### 1.1 Obiettivo e perimetro
`ingestion-elettrico-ammissibilita` gestisce la validazione ammissibilità (file e POD) per flussi elettrici/SMIS, con controlli preliminari su aggiornamento tabelle RCU/RCUGAS.

### 1.2 Stack tecnologico attuale
- Spark `2.4.0.cloudera2`
- Scala `2.11.12`
- Java `8`
- Maven + shade
- Script operativi in `src/main/resources/deploy/bin`

### 1.3 Architettura logica
- **Entrypoint:** `it.eng.au.ammissibilita.CheckAmmissibilitaDriver`
- Driver:
  - parse args
  - init environment (`EE` o `SMIS`)
  - check aggiornamento Sqoop RCU
  - run validazione file (`CheckAmmissibilitaFile`)
  - run validazione POD (`CheckAmmissibilitaPod`)
- Script deploy principale: `bin/flusso-misure-ammissibilita.sh`

### 1.4 Punti sensibili per Spark 3
- Presenza librerie esterne legacy in `deploy/bin` (JDBC/driver).
- Validare comportamento parser/controlli su flow 1G/2G/SMIS.
- Adeguare submit script e configurazioni runtime.

## 2) Funzionamento step by step

1. Script shell prepara parametri runtime ed esegue submit.
2. `CheckAmmissibilitaDriver` legge parametri e inizializza Spark.
3. Esegue controlli pre-condizione su tabelle sqoop.
4. Avvia validazione file.
5. Avvia validazione POD sui file ammessi.
6. Scrive output e termina con esito.
