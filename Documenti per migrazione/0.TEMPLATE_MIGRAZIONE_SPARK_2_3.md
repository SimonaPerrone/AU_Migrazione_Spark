## 3. Modifiche da apportare per migrazione Spark 3
### 3.1 Build e dipendenze
- `spark-core`, `spark-sql`, `spark-hive` -> `_2.12`, Spark 3.5.x
- Scala 2.11 -> 2.12 (o PySpark runtime allineato a Spark 3)
- Rimozione librerie legacy/deprecate

### 3.2 Codice applicativo
- Sostituire API legacy (`HiveContext`, vecchi parser date/time, ecc.)
- Adeguare null semantics / cast / join behavior Spark 3
- Verificare UDF, serializzazione, gestione schema

### 3.3 Config e script
- Aggiornare `spark-submit` (class, conf, risorse)
- Rivedere `spark-defaults.conf` e flag `spark.sql.*`
- Eliminare dipendenze CDH hardcoded non più valide
