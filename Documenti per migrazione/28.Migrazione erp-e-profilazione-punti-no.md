# 28.Migrazioneerp-e-profilazione-punti-no.md

## 1) Descrizione Progetto

### 1.1 Obiettivo e perimetro
`erp-e-profilazione-punti-no` è un progetto multi-modulo (modulo runtime `ERP`) per calcolo ERP/profilazione punti con flussi differenziati (`DIST`, `TERNA`, `IP`, `INT`, `FULL`, `NO`, `SALDO`, `DATI`).

### 1.2 Stack tecnologico attuale
- Parent POM + modulo `ERP`
- Spark `2.4.0.cloudera2`
- Scala `2.11.12`
- Java `8`
- Maven + shade

### 1.3 Architettura logica
- Script deploy: `ERP/src/main/resources/deploy/spark-submit-erp.sh`
- Entrypoint runtime: `it.eng.au.ERP.Main`
- `Main.scala`:
  - parse argomenti (`ERPArgs`)
  - init environment
  - routing su flow e avvio flow specifica
- Test: `EnvironmentSparkTest` + test package `flow`.

### 1.4 Punti sensibili per Spark 3
- Multi-flow con logiche diverse: serve validazione completa su tutti i rami.
- Verifica trasformazioni su dati orari/non orari e saldo.

## 2) Funzionamento step by step

1. Script lancia `Main` con config e parametri flow.
2. `Main` inizializza Spark e parametri operativi.
3. In base al flow richiesto esegue la pipeline dedicata:
   - `DIST`, `TERNA`, `IP`, `INT`, `FULL`, `NO`, `SALDO`, `DATI`.
4. Scrive output ERP e termina.

## 3) Modifiche da apportare ad ogni singola componente
