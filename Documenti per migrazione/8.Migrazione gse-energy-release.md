# gse-energy-release — Migrazione Spark 2 -> Spark 3

## 1. Descrizione Progetto
- **Tipo:** multi-module Maven:
  - `common-module`
  - `gse-calcolo-mensile`
  - `gse-calcolo-annuale`
- **Entry point:** `Driver.scala` nei moduli mensile/annuale.
- **Stack attuale:** Spark `2.4.0.cloudera2`, Scala `2.11.12`, Java 8.

## 2. Funzionamento step by step
1. Script run (`run-gse-energy-release-*.sh`) orchestra:
   - import Sqoop sorgenti
   - job Spark
   - export Sqoop risultati
2. `Driver` (mensile/annuale):
   - parse args
   - init environment
   - lettura tabelle richieste/perimetro/consumi via DAO
   - prepare + join + calcolo consumi
   - scrittura output + export
