# MIGRAZIONE_SPARK3_INDENNIZZI_MISURE_GAS

## 1. Descrizione Progetto
Progetto multi-modulo Spark/Scala per la pipeline completa indennizzi gas:
- indennizzi-misure-gas-common
- calcolo-indennizzi
- pubblicazione-indennizzi
- ammissibilita-rendiconti
- pubblicazione-rendiconti

Stack attuale: Spark 2.4.0.cloudera2, Scala 2.11.12, Java 8.

## 2. Funzionamento step by step del progetto
1. `calcolo-indennizzi`: calcola output tecnico/economico da RCUGAS/TGL.
2. `ammissibilita-rendiconti`: valida ZIP/CSV rendiconti e produce report ammissibilità.
3. `pubblicazione-indennizzi`: pubblica output indennizzi.
4. `pubblicazione-rendiconti`: pubblica rendiconti finali.
5. `common`: fornisce ambiente condiviso, utility e script orchestrazione.

## 3. Modifiche da apportare ad ogni singola componente del progetto
- **Root pom.xml + pom.xml di ogni modulo**
  - Upgrade Spark 2.4 -> Spark 3 target.
  - Upgrade Scala 2.11 -> 2.12.
  - Aggiornamento plugin build/test (scala-maven-plugin, surefire, librerie test).
- **Codice Scala**
  - Verifica compatibilità SQL Spark 3 (date/time, cast, null semantics, parser ANSI).
  - Verifica serializzazione Kryo custom (`CigKryoRegistrator`).
- **Script di deploy**
  - Aggiornare `run-*.sh`/spark-submit con opzioni Spark 3.
- **Config**
  - Allineare `profiles/*/config.properties`, path HDFS/Hive e proprietà runtime.

## 4. Test da prevedere
- Unit test su controller/DAO principali.
- Integration test end-to-end (calcolo -> ammissibilità -> pubblicazione).
- Regression SQL su dataset campione (conteggi, delta, KPI indennizzi).
- Test recovery/restart con executionId.
