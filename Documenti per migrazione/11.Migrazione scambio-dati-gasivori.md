# MIGRAZIONE_SPARK3_SCAMBIO_DATI_GASIVORI

## 1. Descrizione Progetto
Job Spark per pubblicazione dati gasivori con pipeline aggregatori e script di orchestrazione (anche sqoop).

Stack attuale: Spark 2.4, Scala 2.11.

## 2. Funzionamento step by step del progetto
1. Parse argomenti (`ArgsFactory`).
2. Init ambiente Spark (`Environment.getOrCreate`).
3. Esecuzione aggregatori.
4. Export/output tramite script deploy.

## 3. Modifiche da apportare ad ogni singola componente del progetto
- **pom.xml**
  - Upgrade Spark/Scala/plugin test/build.
- **Codice**
  - Verifica compatibilità query Spark SQL e serializzazione in Spark 3.
- **Script deploy**
  - Aggiornare `run-pubblicazione-dati-gasivori.sh` e `spark-submit-*`.
- **Config**
  - Riallineare profili (`prod/test`) e proprietà runtime.

## 4. Test da prevedere

- Integration test su flusso completo con dataset ridotto.
