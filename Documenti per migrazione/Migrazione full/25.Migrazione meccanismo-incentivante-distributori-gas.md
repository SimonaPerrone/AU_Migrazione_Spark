# 25.Migrazionemeccanismo-incentivante-distributori-gas.md

## 1) Descrizione Progetto

### 1.1 Obiettivo e perimetro
Il progetto `meccanismo-incentivante-distributori-gas` (MID) calcola e pubblica output per il meccanismo incentivante gas su più flussi operativi: calcolo standard/back-in-time, predisposizione e pubblicazione MID1/MID2.

### 1.2 Stack tecnologico attuale
- Spark `2.4.0.cloudera2`
- Scala `2.11.12`
- Java `8`
- Maven + shade
- Configurazione tramite properties e arg parsing (`scopt`)

### 1.3 Architettura logica
- **Entrypoint:** `src/main/scala/it/eng/au/mid/Driver.scala`
- **Routing flussi:** match su `flow` (`SBG`, `AGG`, `AGG_BIT`, `MID1_PREP`, `MID2_PREP`, `MID1_PUBB`, `MID2_PUBB`)
- **Script deploy:** famiglia `run_mid_*.sh` (es. `run_mid_agg_standard.sh`, `run_mid_sbg_standard.sh`, `run_mid1_preparazione.sh`, ...)

### 1.4 Punti sensibili per Spark 3
- Verifica semantica SQL/date/null nelle flow calcolo e pubblicazione.
- Ritaratura conf runtime (dynamic allocation, shuffle, memory overhead).
- Aggiornamento script da `spark2-submit` a `spark-submit`.

## 2) Funzionamento step by step

1. Lo script di deploy invoca `it.eng.au.mid.Driver` con flow e properties.
2. `Driver` inizializza Spark environment e logging versione.
3. Esegue routing sul flow richiesto.
4. Viene eseguita la pipeline specifica (calcolo AGG/SBG/AGG_BIT o pubblicazione MID1/MID2).
5. Produce output e termina il job.
