# MIGRAZIONE_SPARK3_SGS_FLUSSO_STORICO_GAS

## 1. Descrizione Progetto

### 1.1 Obiettivo e contesto
`sgs-flusso-storico-gas` implementa una pipeline storica gas articolata in tre fasi principali:
1. **Perimetro**
2. **Aggregazione**
3. **Pubblicazione**

Le fasi sono orchestrate da script workflow e possono essere eseguite in sequenza.

### 1.2 Perimetro funzionale e tecnico
- Calcolo perimetri (SWG/UIG/VTG) su date di competenza.
- Aggregazioni su dataset storici.
- Pubblicazione finale su output dati/tabelle.
- Tracciamento esecuzioni via execution track.
- Integrazione con script `sqoop` e risorse `xsd`.

### 1.3 Architettura logica
- **Codice**: package `it.eng.au.sgsFlussoStoricoGas`
- **Run layer**:
  - `run/perimetro/Driver.scala`
  - `run/aggregazione/Driver.scala`
  - `run/pubblicazione/Driver.scala`
- **Supporto**: `controller`, `dao`, `schema`, `utility`, `model`
- **Orchestrazione**: `run_sgs_workflow.sh` richiama:
  - `run_sgs_perimetro.sh`
  - `run_sgs_aggregazione.sh`
  - `run_sgs_pubblicazione.sh`
- **Test**: presenti su component/controller/utility.

### 1.4 Stack tecnologico attuale
- Spark `2.4.0.cloudera2`
- Scala `2.11.12`
- Java 8
- Maven + test Scala
- Script operativi multipli in `src/main/resources/deploy`

---

## 2. Funzionamento step by step del progetto

1. Viene avviato `run_sgs_workflow.sh`.
2. Step 1: esecuzione driver **Perimetro**.
3. Il modulo perimetro legge raw, calcola perimetri e aggiorna execution track.
4. Step 2: esecuzione driver **Aggregazione**.
5. Il modulo aggregazione elabora dataset per la fase di consolidamento.
6. Step 3: esecuzione driver **Pubblicazione**.
7. Il modulo pubblicazione produce output finali.
8. Il workflow termina con esito complessivo (error handling step-by-step).

## 5. Glossario minimo
- **Perimetro**: selezione/normalizzazione del dominio dati in ingresso.
- **Aggregazione**: consolidamento dati per reporting/elaborazioni successive.
- **Pubblicazione**: esposizione/scrittura finale degli output.
- **Execution track**: tracciatura tecnica delle esecuzioni batch.
