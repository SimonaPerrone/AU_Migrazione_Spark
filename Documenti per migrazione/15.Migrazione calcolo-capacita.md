# MIGRAZIONE_SPARK3_CALCOLO_CAPACITA

## 1. Descrizione Progetto
Progetto legacy critico:
- Spark 1.6.0-cdh5.12.1
- Scala 2.10
- uso di SQLContext/HiveContext
- dipendenze legacy (`spark-assembly`, `spark-csv`)

Entrypoint: `Main.scala` + `SparkImplicit.scala`.

## 2. Funzionamento step by step del progetto
1. Inizializzazione contesti Spark legacy.
2. Esecuzione flow `CalcoloCtcFlow`.
3. Scrittura output.
4. Orchestrazione tramite script deploy.

## 3. Modifiche da apportare ad ogni singola componente del progetto
- **pom.xml (refactor principale)**
  - Spark 1.6 -> Spark 3.
  - Scala 2.10 -> 2.12.
  - Rimozione dipendenze obsolete (`spark-assembly`, `spark-csv` legacy).
- **Codice**
  - Migrare `SQLContext/HiveContext` -> `SparkSession`.
  - Adeguare API DataFrame e query SQL.
- **Script**
  - Revisione completa submit/import/export per Spark 3.
- **Config**
  - Validazione profili e query storiche.

## 4. Test da prevedere
- Unit test su flow/component principali.
- Test semantico SQL su dataset storico.
- Test E2E con confronto output legacy vs Spark3.
- Test recovery e robustezza script.
