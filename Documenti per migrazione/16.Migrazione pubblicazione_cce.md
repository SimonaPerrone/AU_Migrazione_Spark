# MIGRAZIONE_SPARK3_PUBBLICAZIONE_CCE

## 1. Descrizione Progetto

### 1.1 Obiettivo e contesto
`pubblicazione_cce` gestisce la pubblicazione CCE multi-flusso (P/PR/PEIN/PREIN/CA), con pipeline Spark e script esterni di import/export/refresh.  
Stack attuale Spark 2.4 / Scala 2.11, quindi migrazione Spark 2 -> 3 con impatto medio.

### 1.2 Perimetro funzionale e tecnico
- Entrypoint `it.eng.au.pubblicazione_cce.Driver`.
- Parsing argomenti via `ArgsFactory` (`-p`, `-d`, `-f`).
- Dispatch a flow specifici in base al processo.
- Deploy articolato: `runSpark.sh`, `runPubblicazioni*.sh`, `importRichieste.sh`, `exportEsiti.sh`, `refresh_impala.sh`.

### 1.3 Architettura logica
1. Validazione input e creazione contesto Spark.
2. Selezione processo (P/PR/PEIN/PREIN/CA).
3. Esecuzione flow di pubblicazione relativo.
4. Persistenza risultati e file di esito.
5. Script operativi per integrazione con sorgenti/destinazioni esterne.

### 1.4 Tecnologie e dipendenze principali
- Java 8
- Scala 2.11.12
- Spark 2.4.0 Cloudera (`core/sql/hive`)
- Maven + scala-maven-plugin + shade
- Scalatest/JUnit
- `kryo-serializers` per serializzazione

---

## 2. Funzionamento step by step del progetto

1. Lo script `runSpark.sh` prepara run Spark e parametri (`data richiesta`, `flow`).
2. Viene invocato `spark2-submit` con classe `it.eng.au.pubblicazione_cce.Driver`.
3. Il `Driver` esegue parsing argomenti (`ArgsFactory`) e crea environment.
4. Vengono lette proprietà di configurazione e inizializzato appName.
5. In base al valore `flow`, il driver seleziona DAO/flow dedicato.
6. Si esegue la pubblicazione per processo specifico (P/PR/PEIN/PREIN/CA).
7. Gli script di supporto gestiscono import richieste e export esiti.
8. `refresh_impala.sh` riallinea metadati/query layer quando necessario.
9. Il processo termina con logging applicativo e output finali.

## 5. Glossario minimo
- **Flow**: variante di processo pubblicazione (P/PR/PEIN/PREIN/CA).
- **Dispatch**: selezione dinamica del flow in base all’input.
- **Refresh Impala**: riallineamento metadati dopo aggiornamenti dati.
