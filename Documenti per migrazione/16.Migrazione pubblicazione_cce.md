# MIGRAZIONE_SPARK3_PUBBLICAZIONE_CCE

## 1. Descrizione Progetto
Job Spark per pubblicazione CCE multi-flusso (P/PR/PEIN/PREIN/CA), con script esterni per import/export/refresh.

Stack attuale: Spark 2.4, Scala 2.11.

## 2. Funzionamento step by step del progetto
1. Parse argomenti e init environment Spark.
2. Selezione flusso da `Driver`.
3. Esecuzione flow di pubblicazione.
4. Script esterni per import/export/refresh e rilascio.

## 3. Modifiche da apportare ad ogni singola componente del progetto
- **pom.xml**
  - Upgrade Spark/Scala/plugin test/build.
- **Codice**
  - Verifica compatibilità SQL Spark 3 su flow/dao.
- **Script deploy**
  - Aggiornare `runSpark.sh`, `runPubblicazioni*.sh`, script import/export.
- **Config**
  - Riallineare profili e proprietà output/path.

## 4. Test da prevedere
- Unit test su flow/dao principali.
- Test per ogni processo (P/PR/PEIN/PREIN/CA).
- Integration test con script esterni.
- Validazione output file/tabelle finali.
